This is where Pydantic comes in. Pydantic is a powerful data validation library that comes built into FastAPI, and it's one of the main reasons FastAPI is so popular among developers.
Pydantic is a Python library that uses Python's type hints to validate data. It ensures that the data your application receives matches the structure and types you expect.
Step 1 : Observe schemas.py
What's happening here?

UserCreate: Used when creating a new user. All fields (except bio) are required.
name must be 1-50 characters
email must be a valid email format
age must be between 0 and 150
bio is optional
UserUpdate: Used when updating a user. All fields are optional (you might only want to update the email, for example).
UserResponse: Used for sending user data back to the client. Includes a user_id and status.

Step 2 : Observe api.py
What changed?

Functions now accept Pydantic model instances instead of individual parameters
create_user takes a UserCreate object
update_user takes a UserUpdate object
We're returning UserResponse objects with validated structure
The model_dump(exclude_none=True) method converts the Pydantic model to a dictionary, excluding fields that are None
Step 3 : Observe main.py
What changed?

We import the Pydantic models from schemas
POST endpoint now accepts UserCreate as a parameter
PUT endpoint now accepts UserUpdate as a parameter
FastAPI automatically validates the request body against these models
